ÉVALUATION, CHARGE ATELIER, RTA, GÉNÉRATION TP — V15

CORRECTION FIREBASE MULTIPOSTE / PURGE COMPLÈTE

Cette version corrige le cas où des évaluations ou des séances Atelier du jour restaient dans Firebase après suppression des listes d'élèves.

Modifications :
- la commande « Sauvegarder + supprimer toutes les listes » supprime maintenant en cascade :
  • tous les élèves ;
  • toutes les évaluations ;
  • toutes les séances Atelier du jour ;
- purge effectuée directement dans l'espace Firebase central partagé, même pour des documents absents du cache local ;
- suppression des opérations Firebase différées pouvant recréer des données après la purge ;
- nettoyage du stockage local Atelier du jour ;
- contrôle final obligatoire : 0 élève, 0 évaluation, 0 séance Atelier dans Firebase ;
- nettoyage non bloquant de l'ancien espace users/{uid} du compte Firebase connecté ;
- le diagnostic Firebase est mis à jour immédiatement après la purge.

Les classes, professeurs, référentiels et situations professionnelles sont conservés.
