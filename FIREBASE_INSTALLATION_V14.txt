EVALUATION & CHARGE ATELIER V14 — MISE EN SERVICE FIREBASE
==========================================================

Projet Firebase prévu dans l’application : evaluation-competences-mv

1. Dans Firebase Console, ouvrir Authentication > Sign-in method.
2. Activer la méthode « Adresse e-mail / Mot de passe ».
3. Créer au moins un compte utilisateur destiné au logiciel.
4. Ouvrir Firestore Database et créer la base si elle n’existe pas encore.
5. Publier le contenu du fichier firestore.rules dans l’onglet Règles de Firestore.
6. Ouvrir Evaluation_Charge_atelier_V14.html avec une connexion internet.
7. Se connecter avec le compte Firebase créé.
8. Vérifier le voyant puis cliquer sur « Synchroniser maintenant ».

DONNÉES SYNCHRONISÉES
=====================
- classes, élèves et évaluations ;
- comptes professeurs et paramètres ;
- situations professionnelles ;
- publications de l’Atelier du jour ;
- affectations, supports et chef d’équipe ;
- auto-évaluations ;
- états des évaluations du jour.

Les séances atelier sont enregistrées dans users/{uid}/atelierSessions avec un
document distinct par classe et par date. Les données de chaque utilisateur sont
isolées par les règles Firestore fournies.

MODE LOCAL
==========
Le mode local reste disponible dans Paramètres > Administration / Développement.
