IMPORTANT — FIREBASE :
Cette version démarre volontairement en MODE LOCAL.
Même si une version précédente avait Firebase activé dans le même navigateur,
la V6 utilise une nouvelle clé de préférence et ne se connecte pas automatiquement.

Activation : Paramètres > Mode développement local / Firebase > Activer Firebase.
Après activation, l'application redémarre et demande la connexion Firebase.

Règles Firestore fournies : accès lecture/écriture réservé aux utilisateurs Firebase authentifiés.
Avant tout déploiement en production, vérifier les règles et les comptes autorisés.
