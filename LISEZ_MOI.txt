CORRECTIF — IMPORT ET PERSISTANCE DES ÉLÈVES

Modifications de cette version :
- lecture Excel renforcée : recherche automatique de la bonne feuille et des colonnes Nom / Prénom ;
- import de toutes les lignes élèves, avec gestion fiable des CSV et XLSX ;
- contrôle local après import : chaque élève créé doit être retrouvé dans IndexedDB ;
- synchronisation Firebase du lot importé avec vérification distante ;
- un marqueur protège les élèves nouvellement importés tant que Firebase ne les a pas confirmés ;
- une liste Firebase ancienne ou partielle ne peut plus faire disparaître immédiatement les élèves venant d’être importés ;
- la liste affichée après import est relue depuis IndexedDB, puis recomptée ;
- message final indiquant le nombre importé et le nombre total présent dans la classe.

Toutes les fonctions précédentes du logiciel sont conservées.

VERSION — NAVIGATION ÉVALUATIONS CORRIGÉE

Corrections de cette version :
- correction de l’ouverture « Évaluation de rentrée » ;
- correction de l’ouverture « Évaluation sur fiche d’activités » ;
- correction de la détermination du diplôme : la fonction utilisait une variable de classes non garantie, provoquant une erreur JavaScript silencieuse ;
- utilisation désormais de la liste réelle des classes via getClasses() et de la classe de l’élève ;
- ajout d’un message explicite si une erreur d’ouverture se reproduit ;
- conservation de l’affichage/impression stricts au diplôme de l’élève.

=== CORRECTIF FICHE D’ACTIVITÉ — studentClass ===
- Correction de l’erreur « studentClass is not defined ».
- La classe de l’élève est maintenant calculée explicitement avant l’affichage de la fiche d’activité.
- Les compétences de la fiche sont filtrées à partir du diplôme réel de l’élève sélectionné.
- Le clic sur une activité ouvre de nouveau correctement la fiche d’évaluation.

MODIFICATIONS DE CETTE VERSION

- Synthèse élève imprimable / PDF : restauration des barres graphiques de positionnement.

MODIFICATIONS DE CETTE VERSION
==============================
- Toutes les évaluations actives notées participent désormais aux calculs de moyenne :
  évaluations classiques, situations professionnelles, rétroactives, évaluations de rentrée et fiches d’activités.
- Les évaluations de rentrée et les fiches d’activités alimentent aussi la synthèse par compétence via leurs compétences associées.
- Dans la synthèse élève, le positionnement d’une compétence est maintenant calculé à partir de la moyenne de toutes les évaluations actives associées sur la période sélectionnée.
- Toute évaluation archivée est systématiquement exclue des moyennes et de la synthèse.
- L’archivage reste réversible et séparé de la suppression.
- Ajout d’une suppression définitive d’une évaluation pour le professeur, avec confirmation.
- Ajout de la suppression définitive pour les évaluations collectives et depuis la page des archives.
- Après ajout, modification, archivage, restauration ou suppression, les calculs sont recalculés à partir des données actives au prochain affichage de la synthèse.

MODIFICATIONS DE CETTE VERSION
==============================
- Ajout d’un champ « Support d’activité » pour les évaluations par situation professionnelle.
- Ajout du même champ pour les évaluations sur fiche d’activités.
- Le support peut être saisi sous forme libre : véhicule, organe, maquette, moteur, véhicule client, etc.
- Le support d’activité est conservé lors de l’enregistrement et de la modification d’une évaluation.
- Pour les fiches d’activités, le support est également reporté sur la fiche imprimable.
- Dans les historiques visibles, le support d’activité apparaît sous l’intitulé de la situation lorsqu’il est renseigné.
- Les corrections précédentes sur les moyennes, archives et suppression des évaluations sont conservées.

MODIFICATIONS DE CETTE VERSION
==============================
- Les évaluations sur fiche d’activités peuvent maintenant être réalisées en mode Individuel ou Collectif.
- En mode Collectif, tous les élèves de la classe sont sélectionnés par défaut.
- Le professeur peut désélectionner certains élèves avant de choisir la fiche d’activité.
- La note, les critères 0/1/2, l’appréciation, les observations et le support d’activité saisis sont enregistrés pour chaque élève sélectionné.
- Les évaluations créées ensemble reçoivent un identifiant collectif commun et sont regroupées dans l’historique sous « Évaluation collective ».
- Chaque élève conserve ensuite sa propre évaluation dans son historique et ses calculs de moyenne/synthèse.
- La modification ultérieure d’une fiche reste individuelle afin de permettre d’ajuster un élève sans modifier les autres.

MODIFICATIONS DE CETTE VERSION
==============================
- Ajout d’un bouton/type d’évaluation distinct : « Évaluation collective sur fiche d’activités ».
- Ce choix apparaît directement sur l’écran « Nouvelle évaluation ».
- L’ouverture de ce type active immédiatement le mode collectif.
- Tous les élèves de la classe sont sélectionnés par défaut.
- Le professeur peut retirer certains élèves avant de choisir la fiche d’activité.
- Une évaluation individuelle est enregistrée pour chaque élève sélectionné, avec un même identifiant collectif.
- Les évaluations sont regroupées dans l’historique mais alimentent séparément les moyennes et synthèses de chaque élève.
- Le support d’activité reste disponible pour cette évaluation collective.
- Le cache PWA/service worker a été changé pour forcer l’affichage de cette nouvelle version sur iPad et navigateur.
