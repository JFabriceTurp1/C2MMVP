ÉVALUATION, CHARGE ATELIER, RTA, GÉNÉRATION TP — VERSION 4
=========================================================

Principales évolutions :

1. MODULE BILANS — BILAN PAR ÉLÈVE
- Choix d'une période de bilan puis d'un élève.
- Création / réouverture d'un bilan individuel.
- Le bilan est figé à la date de clôture de la période sélectionnée.
- Périodes rétroactives 2025-2026 conservées :
  P1 : 10/10/2025
  P2 : 05/12/2025
  P3 : 27/03/2026
  P4 : 12/06/2026
- Le bilan reprend un positionnement par compétence, les évaluations retenues et l'observation de période rétroactive disponible.
- Date d'édition / signature modifiable manuellement.
- Impression A4 dédiée.
- Enregistrement des bilans dans l'historique avec possibilité de rouvrir / rééditer / imprimer.
- Fonction "Actualiser avec les évaluations" volontaire : un bilan déjà enregistré reste un instantané tant qu'il n'est pas actualisé.

2. FIREBASE — RÉACTIVATION CORRIGÉE
- Le mode Firebase est maintenant réellement activable depuis Paramètres.
- Les SDK Firebase nécessaires sont chargés lorsque la connexion Internet est disponible.
- Au passage du mode local au mode Firebase, une synchronisation de remontée locale est demandée avant le rapatriement du cloud.
- Les classes, élèves et évaluations locales sont envoyés vers Firebase lors de cette réactivation.
- Les périodes de bilan, bilans élèves, synthèses enregistrées et observations rétroactives sont désormais inclus dans la configuration synchronisée.
- Le drapeau de remontée locale n'est supprimé qu'après une synchronisation terminée avec succès.

IMPORTANT
---------
La vérification réalisée sur cette version est une vérification du code et de la logique de synchronisation.
La connexion réelle au projet Firebase nécessite une connexion Internet et les identifiants Firebase du compte ; elle doit donc être testée sur le poste utilisateur avant utilisation en production.

Le mode local reste le mode par défaut : Firebase ne s'active qu'après action volontaire depuis Paramètres.
