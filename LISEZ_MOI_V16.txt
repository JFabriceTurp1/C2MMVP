EVALUATION & CHARGE ATELIER — V16 CORRIGÉE
===========================================

Corrections complémentaires du 10/09/2026 :

1. SORTIE DE LA VISION ÉLÈVE
- Pour quitter la Vision élève, le logiciel demande exclusivement le code personnel du professeur actuellement connecté.
- Le message affiche clairement le professeur concerné.
- Le code administrateur n'est pas utilisé comme code de sortie, sauf si l'administrateur est lui-même le professeur actuellement connecté.

2. ACTIVITÉ DU JOUR PERSONNALISABLE
- Ajout dans « Administration du jour » d'un bloc « Activité du jour personnalisable ».
- Le professeur peut saisir : intitulé, description courte, support (ex. Honda Jazz) et nombre de places.
- Le bouton « Créer et sélectionner » ajoute l'activité du jour ; il reste ensuite à cliquer sur « Publier pour aujourd'hui ».
- L'activité personnalisée apparaît dans le Tableau du jour et peut être affectée aux élèves comme les autres activités.
- Elle alimente également l'auto-évaluation de l'élève (activité, support, note estimée et trois indicateurs).
- Une activité personnalisée non affectée peut être supprimée.
- « Effacer uniquement les choix du jour » efface aussi les activités personnalisées du jour.
- Lorsqu'une activité personnalisée est ouverte en évaluation, elle arrive dans le mode d'évaluation libre : le professeur choisit alors les compétences à évaluer.

3. ÉLÉMENTS V16 CONSERVÉS
- Remontée de l'auto-évaluation élève vers les fiches de validation.
- Affichage du support travaillé et du professeur évaluateur dans l'historique et les synthèses.
- Présentation plus lisible de l'historique des évaluations.

Base : Evaluation_Charge_atelier_V15.
